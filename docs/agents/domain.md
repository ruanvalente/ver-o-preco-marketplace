# Domain docs

Decisões de domínio e arquitetura são registradas em `docs/adr/`.

- Consulte os ADRs relevantes ao módulo antes de propor mudanças que afetem limites de domínio, modelagem ou regras de negócio.
- Use o vocabulário já adotado em `PRODUCT.md`, `docs/architecture/` e nos ADRs, em vez de introduzir sinônimos para conceitos existentes.
- Se uma proposta contradizer um ADR, sinalize o conflito explicitamente e explique por que a decisão deve ser reaberta, em vez de ignorá-la silenciosamente.

Se `docs/adr/` ainda não existir, siga em frente sem alertar: o diretório é criado conforme decisões passam a ser registradas.
